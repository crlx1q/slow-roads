# Мод-слой slow-roads (v0.1.0)

Игра в этом репозитории — готовый минифицированный билд (исходников нет, см. `ARCHITECTURE.md`).
Поэтому доработки сделаны **наложенным слоем**: отдельные файлы в `mods/`, которые подключаются
двумя строками в `index.html`. Сам билд не тронут: содержимое оригинального `index.html`
сверено по git-blob-хешу (`9a3918b5…`) до вставки тегов, инлайн webpack-рантайм не изменён.

```
mods/sr-mod.js    логика мода
mods/sr-mod.css   оформление
```

Подключение в `<head>`:

```html
<script src="./alea.min.js"></script><script src="./mods/sr-mod.js"></script>
...
<link href="./static/css/main.8b77de6a.chunk.css" rel="stylesheet"><link href="./mods/sr-mod.css" rel="stylesheet"/>
```

Чтобы полностью отключить мод — удалить эти два тега.

## Что делает

### 1. Чистка мусора
Скрываются донат/соц-ссылки и их обёртки: Ko-fi, Patreon, PayPal, Buy me a coffee,
Discord, Twitter/X, Reddit, Instagram, YouTube, TikTok, а также иконка `ico_kofi.svg`
и элементы с классами `kofi / donate / patreon / discord / social`.
Работает в два слоя: CSS-правила (мгновенно, до отрисовки) и `MutationObserver`
(на случай, если React дорисует кнопку позже).
Список правил — в начале `mods/sr-mod.css` и в `JUNK_HREF` / `JUNK_TEXT` в `mods/sr-mod.js`.

### 2. Сохранение параметров
Состояние сохраняется двумя уровнями:

| Уровень | Что | Когда |
| --- | --- | --- |
| `localStorage` | все ключи игры (настройки, режим, локация, транспорт, сезон) + счётчики мода | каждые 5 с и при закрытии вкладки |
| Сервер (опционально) | тот же снимок целиком | каждые 20 с + `sendBeacon` при выходе |

При загрузке мод сравнивает `updatedAt` локального и серверного снимка. Если серверный
новее — он записывается в `localStorage` и страница один раз перезагружается
(флаг в `sessionStorage`, чтобы не было цикла), после чего игра читает уже
восстановленные настройки. Так профиль переносится между браузерами и устройствами.

Собственные счётчики мода: общий пробег (`odoKm`), пробег поездки (`tripKm`),
время за рулём (`driveSec`), видимость панелей.

GitHub Pages — статический хостинг и сервером быть не может, поэтому серверная часть
вынесена отдельно: `server/worker.js` (Cloudflare Worker + KV, бесплатного тарифа хватает).
После деплоя достаточно один раз выполнить в консоли игры:

```js
SRMOD.setEndpoint("https://<имя>.workers.dev")
```

### 3. Приборная панель
Воспроизведена компоновка оригинала: слева дуга скорости (голубая) с цифрами и `KPH`,
по центру одометр в стиле `000`+`16` `KM`, надпись `CRUISE` и часы, справа дуга
мощности с градиентом зелёный→жёлтый, ниже метки `RWD` и фар, по краям — стрелки поворотников.

В нашем билде интерьер отрисован без приборки вообще (серый салон без текстур и экранов) —
оригинальная панель рисуется движком на меше и в этом билде отсутствует, поэтому она
сделана экранным оверлеем, а не восстановлением 3D-панели.

### 4. Центральный экран
Большой чёрный экран в стиле Li / Zeekr под приборкой: время, дата, температура-заглушка,
скорость крупными цифрами, режим `D`, TRIP / ODO / TIME, схема машины сверху с шестью
лампами поворотников, строка медиа-заглушки и индикатор режима сохранения
(`local save` / `server save`).

### 5. Поворотники
`Z` — левый, `X` — правый, оба вместе — аварийка. Частота 430 мс, тихий щелчок реле
через WebAudio. Одновременно зажигаются: стрелка в приборке, соответствующие лампы
на схеме машины (перед, борт, зад) и подсветка по краям экрана — сверху (перед),
по бокам (повторители), снизу (зад).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Z` / `X` | левый / правый поворотник |
| `Z` + `X` | аварийка |
| `F2` | приборка вкл/выкл |
| `F4` | центральный экран вкл/выкл |
| `F8` | диагностика в консоль (глобалы игры, ссылки, источник телеметрии) |

## Настройки и API

До подключения мода можно объявить:

```html
<script>window.SR_MOD_CONFIG = { sound: false, maxKph: 200, debug: true, saveEndpoint: "https://..." }</script>
```

В рантайме доступен `window.SRMOD`:

| Вызов | Что делает |
| --- | --- |
| `SRMOD.setEndpoint(url)` | прописать сервер сохранений и перезагрузить |
| `SRMOD.save.now()` | отправить снимок на сервер немедленно |
| `SRMOD.save.export()` | скачать сохранение файлом |
| `SRMOD.save.wipe()` | стереть сохранение мода |
| `SRMOD.setTelemetry(kph)` | задать скорость вручную (для отладки приборки) |
| `SRMOD.scan()` | то же, что `F8` |
| `SRMOD.killJunk()` | повторить чистку мусора |

## Ограничения (честно)

1. **Скорость.** Мод не имеет доступа к физике: значение берётся из HUD самой игры
   (поиск элемента с `KPH`/`MPH` в DOM) или из `SRMOD.setTelemetry()`. Если HUD скрыт
   или верстка другая — цифры покажут `--`, а дуги останутся пустыми. `F8` печатает,
   что удалось найти; по этому выводу подбирается точный хук.
2. **CRUISE / RWD / фары** — пока статичные метки: их состояние живёт внутри бандла.
3. **Поворотники** — оверлей, а не настоящие 3D-лампы на кузове: добавить материалы и
   источники света в сцену без доступа к движку нельзя.
4. **Камера от третьего лица мышью** и **сохранение точной позиции на трассе** требуют
   вмешательства в минифицированный бандл (694 КБ) либо пересборки игры из исходников.
   Сначала нужно найти объекты сцены/камеры/транспорта — для этого и добавлен `F8`.
5. **Мультиплеер** — см. `MULTIPLAYER.md`.
